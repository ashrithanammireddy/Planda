Tour media
==========

Each feature slide shows the best file it finds, in this order:
  1. <name>.mp4   a short looping screen recording (BEST - it animates)
  2. <name>.gif   an animated gif
  3. <name>.png   a static screenshot
  4. (nothing)    falls back to an icon

So an .mp4 wins if present. Missing files just fall back, so you can add them
one at a time.

Names (use these exactly):
  calendar      Month view with a few colored events
  add           Tapping + and adding a test/quiz/homework
  study         Auto-generated study sessions appearing before a test
  ask-planda    Asking Planda a question and getting a reply
  grades        The Grades card dashboard (GPA + class cards)
  friends       The Friends leaderboard / adding a friend
  classes       Settings > Manage Classes (colors), or sidebar calendars
  focus         The Focus Room / focus timer running

Recording tips for the .mp4 (keeps it small and clean):
  - 3 to 6 seconds, it loops automatically
  - portrait / phone-sized looks best in the card
  - it plays muted, so audio does not matter
  - keep each file under a few MB if you can

Not needed (these use the panda / an icon):
  welcome, "you are all set"
